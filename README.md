# portafolio

> *Mi portafolio personal: quién soy, lo que hago y lo que me gusta.* → **[paginas.wattnbeaver.site/portafolio](https://paginas.wattnbeaver.site/portafolio/)**

Minimalista y cálido, hecho a mano **sin frameworks ni librerías**: HTML, CSS y un poco de JavaScript.

- ✍️ **Título que se arma letra por letra** con una curva de resorte (`linear()` en CSS) y un subrayado que se dibuja.
- 🟠 **Retícula de puntos** que sigue al cursor o al dedo con física de resorte (canvas + `requestAnimationFrame`).
- 📜 **Revelaciones al hacer scroll** con `IntersectionObserver`, un párrafo que se ilumina palabra por palabra
  y una línea de tiempo que se dibuja mientras bajas.
- 🎞️ **Mini-animaciones vivas** en cada proyecto que solo corren cuando están a la vista.
- 🌗 Modo claro/oscuro automático, **español/inglés**, y respeto a "reducir movimiento".
- 💬 Comentarios y contacto: los guarda una API chiquita en mi Raspberry Pi y **yo apruebo cada comentario** desde
  Telegram con mi asistente [KORRA](https://github.com/Chava33165/korra-asistente) antes de que se publique.

Se sirve con Caddy desde mi homelab, detrás de un Cloudflare Tunnel.
